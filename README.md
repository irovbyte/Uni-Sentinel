# 🛡️ Uni-Sentinel

![Version](https://img.shields.io/badge/version-1.0.0-blue.svg)
![Python](https://img.shields.io/badge/python-3.8+-yellow.svg)
![License](https://img.shields.io/badge/license-MIT-green.svg)
![Platform](https://img.shields.io/badge/platform-Linux%20%7C%20macOS-lightgrey)

**Uni-Sentinel** — это мощный, универсальный и полностью автоматизированный инструмент для локального CI/CD. Он проводит глубокий аудит вашего кода, компилирует проект, запускает тесты и проверяет память на утечки одной командой.

> *Больше не нужно запускать `clang-format`, `make`, `leaks` и тесты вручную. Uni-Sentinel сделает это за вас.*

---

## 🚀 Установка (Одной командой)

Просто вставьте эту строку в терминал. Скрипт сам установит зависимости, настроит алиасы и подготовит к работе.

```bash
bash <(curl -s https://raw.githubusercontent.com/irovbyte/Uni-Sentinel/main/install.sh)
```

*(После установки перезапустите терминал или напишите `source ~/.zshrc`)*

## 🔥 Возможности

### 🧠 Умное сканирование
* **Авто-детект языка:** Сам понимает, работаете вы с **C** или **Python**.
* **Рекурсивный поиск:** Находит `Makefile` и бинарники, даже если они спрятаны глубоко в подпапках (`src/cat`, `src/grep` и т.д.).
* **Глобальный поиск бинарников:** Если проект собирается в `build/` или корень — Sentinel найдет исполняемый файл.

### 💂 C-Language Guard (Си)
* **Стиль кода:** Автоматический запуск `clang-format` (Google Style).
* **Умный конфиг:** Если у вас нет `.clang-format`, он найдет его в папке `materials` или предложит дефолтный.
* **Структурный анализ:** Проверяет код на соответствие "7 принципам структурного программирования":
    * 🚫 Запрет на `goto`.
    * 📏 Функции не длиннее 50 строк.
    * 📦 Проверка вложенности.
* **Сборка:** Автоматический `make clean && make all` во всех подпроектах.
* **Тесты:** Запуск `make test` или **Smoke Tests** (проверка запуска), если unit-тестов нет.
* **Память:** Интеграция с **Valgrind**. Парсит вывод и сообщает, если есть утечки (даже если программа вернула ошибку логики).

### 🐍 Python Guard (Питон)
* **Стиль:** Проверка через `flake8` (PEP8).
* **Синтаксис:** Компиляция в байт-код для проверки ошибок синтаксиса.
* **Тесты:** Автозапуск `pytest`.

### 🛠 Удобство (UX)
* **Авто-обновление:** Команда `uni-sentinel update` сама подтянет свежую версию с GitHub.
* **Чистота:** Автоматический `make clean` до и после проверки. Никакого мусора.
* **Информативность:** Красивый цветной лог, паузы для чтения, четкие вердикты **[OK]** / **[FAIL]**.

## 📖 Использование

Перейдите в папку с любым проектом и введите:

```bash
uni-sentinel
```

### Дополнительные команды

| Команда | Описание |
| :--- | :--- |
| `uni-sentinel` | Запустить полную проверку текущей директории |
| `uni-sentinel update` | Обновить утилиту до последней версии |
| `uni-sentinel help` | Показать справку |

## ⚙️ Требования

* **OS:** Linux (Ubuntu/Debian/Arch) или macOS.
* **Python:** 3.6 или выше.
* **Зависимости (для C):** `gcc`, `make`, `valgrind`, `clang-format`.
* **Зависимости (для Python):** `flake8`, `pytest`.

## 🤝 Вклад в проект (Contributing)

Архитектура Uni-Sentinel модульная. Хотите добавить поддержку **C++**, **Go** или **Rust**?

1.  Создайте файл `handlers/cpp_handler.py`.
2.  Наследуйтесь от `BaseHandler`.
3.  Реализуйте методы `check_style`, `build`, `run_tests`.
4.  Добавьте условие в `core/scanner.py`.
